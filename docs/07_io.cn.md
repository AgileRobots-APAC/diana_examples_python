# 07 I/O

Diana API 提供数字量和模拟量 I/O 访问接口。

## 数字输入

```python
ret, value = api.readDI("board", "di0", ip)
```

## 数字输出

```python
ret, value = api.readDO("board", "do0", ip)
api.writeDO("board", "do0", value, ip)
```

`group_name` 常见示例包括：

```text
board
plc
endpoint
```

具体信号名称和接线请以控制箱 I/O 配置为准。

## 模拟量

读取接口同时返回 mode 和 value：

```python
ret, mode, value = api.readAI("board", "ai0", ip)
ret, mode, value = api.readAO("board", "ao0", ip)
```

模拟输出 `writeAO` 涉及输出模式与有效范围，客户在真实设备上使用前应确认现场接线、模式和负载。

## 仓库例程的安全策略

`06_io` 默认只读，不会改变 DO。

只有显式传：

```bash
python3 examples/06_io/main.py --ip 192.168.10.75 --set-do=1
```

才会调用 `writeDO`。

`06_io` 还读取控制器总线电流、电压，并支持显式 `--set-ao=<mode>:<value>` 写入 AO。AO 写入会影响外部设备，必须先确认控制器信号模式、接线和允许范围。
