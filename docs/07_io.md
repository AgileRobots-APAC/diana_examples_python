# 07 I/O

Diana API provides digital and analog I/O access.

## Digital Input

```python
ret, value = api.readDI("board", "di0", ip)
```

## Digital Output

```python
ret, value = api.readDO("board", "do0", ip)
api.writeDO("board", "do0", value, ip)
```

Common `group_name` examples:

```text
board
plc
endpoint
```

Use the controller I/O configuration as the final reference.

## Analog I/O

Read APIs return mode and value:

```python
ret, mode, value = api.readAI("board", "ai0", ip)
ret, mode, value = api.readAO("board", "ao0", ip)
```

Analog output affects external devices. Confirm wiring, mode, load, and allowed range before writing.

`06_io` is read-only by default. It writes only when explicit options such as `--set-do=1` or `--set-ao=<mode>:<value>` are used.
